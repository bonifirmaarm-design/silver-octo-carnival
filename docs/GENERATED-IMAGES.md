## Почему картинки ещё не на странице

Сетевая политика окружения Claude Code закрывает `gen.krea.ai`,
`app-uploads.krea.ai` и `sferihome.me` (ответ 403). Поэтому скачать эти файлы
и встроить их в страницу я не могу. Страницы-артефакты тоже не показывают
картинки со сторонних доменов.

Два способа это исправить:

1. **Разрешить домены в настройках окружения** — `gen.krea.ai`,
   `app-uploads.krea.ai`, `sferihome.me`. Тогда я сам скачаю картинки и открою
   текущий сайт. Как это сделать:
   https://code.claude.com/docs/en/claude-code-on-the-web
2. **Загрузить картинки в репозиторий** — в папку `redesign/img/`, так же, как
   вы загружали референсы. GitHub для меня открыт.
