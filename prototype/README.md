# Прототип сайта SFERIHOME

Одностраничный прототип редизайна `sferihome.me`. Направление — `docs/DESIGN.md`,
разбор референсов — `docs/REFERENCES.md`, контекст продукта — `PRODUCT.md`.

## Как открыть

- **Одним файлом:** `dist/sferihome-prototype.html`. Шрифты и скрипты внутри,
  открывается двойным кликом, можно переслать.
- **Из исходников:** `index.html`. Работает и без сервера.

Язык выбирается автоматически по браузеру или переключателем ME · RU · EN.
Выбрать язык по ссылке: `?lang=me`, `?lang=ru`, `?lang=en`.
Посмотреть ошибку отправки формы: `?demo=error`.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | разметка; русский текст вшит как запасной вариант без JS |
| `styles.css` | все значения — токены в `:root`, других цветов и размеров в файле нет |
| `i18n.js` | тексты на черногорском, русском и английском |
| `app.js` | языки, типографика переносов, меню, подсветка секции, раскрытие стены, форма |
| `fonts/` | Onest (OFL): латиница, расширенная латиница, кириллица; 400/500/700/800 |
| `tools/wall_section.py` | генератор аксонометрии стены; `--inject` вписывает её в `index.html` |
| `tools/check-i18n.mjs` | проверка: ключи есть во всех языках, запасной русский совпадает со словарём |
| `tools/bundle.py` | сборка `dist/sferihome-prototype.html` |

После правок:

```sh
node tools/check-i18n.mjs
python3 tools/bundle.py
```

## Что проверено

- Ширины 320, 375, 768, 1280, 1440 и 1920 во всех трёх языках: горизонтального
  скролла нет, ошибок в консоли нет.
- На 1280×800 и 1440×900 главная кнопка видна без прокрутки.
- Контраст всего текста — WCAG AA по вычисленным цветам, включая состояния ошибок.
- Форма: ошибки у полей и сводка; снятие ошибки по мере исправления без сдвига
  раскладки; отправка с блокировкой кнопки; успех; ошибка сервера с сохранением
  введённого; перевод всех состояний при смене языка.
- Клавиатура: ссылка «К содержанию», видимый фокус, меню закрывается по Escape
  и возвращает фокус.
- `prefers-reduced-motion`: чертёж стены показывается сразу, без анимации.

## Что в прототипе ненастоящее

Эти места помечены пунктирными плашками «Прототип»; кнопка в подвале их скрывает.

- **Цифры** — из прессы и поисковой выдачи. Их нужно подтвердить у компании.
- **Проекты** — эскизы 1–3 этажей без площадей и цен.
- **Фото цеха** — заглушка.
- **Логотип** — временный.
- **Контакты** — не указаны.
- **Форма** никуда не отправляет данные.
- **Черногорский и английский** тексты — первый черновик, нужна вычитка носителем.
