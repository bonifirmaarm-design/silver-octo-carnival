# silver-octo-carnival

Рабочее окружение Claude Code с установленной библиотекой design/UX-скилов
и правилом их обязательного применения.

## Что внутри

| Путь | Что это |
|---|---|
| `CLAUDE.md` | Правило: любая UI/дизайн-задача идёт через скилы. Ядро, пайплайн, красные линии. |
| `.claude/skills/` | 166 скилов из 14 репозиториев. Claude Code подхватывает их автоматически. |
| `.claude/design-resources/` | 10 готовых направлений `DESIGN.md`, промпты и рецепты. |
| `.claude/hooks/design-skills-reminder.py` | Хук `UserPromptSubmit`: на UI-задачах напоминает правило. |
| `.claude/settings.json` | Регистрация хука. |
| `docs/DESIGN-SKILLS.md` | Полный каталог: скил → источник, коммит, лицензия. |

## Как это работает

Правило из `CLAUDE.md` читается в начале каждой сессии. Хук дополнительно
срабатывает на промптах, похожих на дизайн-задачу (русские и английские
ключевые слова), и подставляет короткое напоминание: загрузить ядро
(`frontend-design`, `impeccable`, `hallmark`, `ui-ux-pro-max`,
`web-design-guidelines`), выбрать визуальное направление до кода, прогнать
результат через ревью.

Скилы вызываются и вручную: `/impeccable`, `/hallmark`, `/frontend-design`,
`/scroll-craft`, `/ui-refactor` и далее по каталогу.

## Обновление скила

Скилы импортированы как есть, без подмодулей. Чтобы обновить — взять свежую
версию из апстрима (коммит-основа указана в `docs/DESIGN-SKILLS.md`) и
заменить каталог в `.claude/skills/`.

## Лицензии

Каждый скил остаётся под лицензией своего источника; файлы `LICENSE`
сохранены внутри каталогов там, где они были в апстриме. Сводка —
в `docs/DESIGN-SKILLS.md`.
