# Редизайн sferihome.me

Одностраничник на фотографиях заказчика. Один файл `index.html` плюс `img/`.

Артефакт: https://claude.ai/artifact/T2nPf6jZJaxhVun9rLib6W (приватный).

## Палитра — снята с фотографий

```
--ground  #EDECE7   прохладная глина: фон, чтобы тёплые кремовые дома читались объектами
--paper   #FBFAF7   карточки
--ink     #000000   текст
--muted   #5C5B52   вторичный текст
--ghost   #7C7B71   вторая половина разорванного заголовка
--straw   #96690F   солома — единственный акцент
--olive   #29331F   кипарисовая тень — тёмные поверхности
--dusk    #0D1422   небо с вечернего кадра, фон блока заявки
```

Фон намеренно холодный: на тёплом кремовом фоне дома с кремовой штукатуркой
растворяются.

## Языки

ME · RU · EN, словарь `I18N` внутри файла. Выбор: по браузеру, из `localStorage`
или параметром `?lang=me|ru|en`. Переносы правятся под каждый язык — тире не
начинает строку, «3–5» не рвётся, короткие предлоги не висят.

Ошибка отправки формы: `?demo=error`.

## Что проверено

- Ширины 390, 768, 1024, 1280 и 1440 во всех трёх языках (15 сочетаний):
  горизонтального скролла нет, ошибок в консоли нет, все восемь фотографий
  загружаются, ни одна кнопка не переносится на две строки.
- Контраст всего текста — WCAG AA по вычисленным цветам, в ru, me и en.
- Форма: ошибки у полей, снятие ошибки по мере исправления, успех,
  ошибка сервера с сохранением введённого.
- Клавиатура: ссылка «К содержанию» первым табом, видимый фокус, меню
  закрывается по Escape и возвращает фокус, подпись бургера меняется
  Меню / Закрыть.
- `prefers-reduced-motion`: анимация первого экрана отключается, страница
  в покое выглядит так же, как после загрузки.

## Что ненастоящее

Написано в подвале страницы: фотографии сгенерированы и не показывают реальные
объекты SFERIHOME; цифры взяты из открытых публикаций и требуют подтверждения
компанией. Контактов и цен нет.

Структура блоков выведена из того, что известно о компании: домен `sferihome.me`
закрыт egress-политикой окружения (`Host not in allowlist`), поэтому текущий сайт
не был просмотрен.
