# Редизайн sferihome.me

Одностраничник на фотографиях заказчика. Один файл `index.html` плюс `img/`.

Артефакт: https://claude.ai/artifact/T2nPf6jZJaxhVun9rLib6W (приватный).

## Направление

Первый экран — снимок во всю ширину, вордмарк SFERI / HOME поверх него,
плавающие плашки с цифрами. Это была просьба заказчика: экран вернуть
как был.

Остальное снято с референсов (Sonder House, Hotle, MK Vita, САК-Строй):
разорванный на чёрную и серую половины заголовок, строки данных
на волосяных линиях, пилюли как единый голос элементов, фотографии
в скруглённых карточках с отступом.

```
--ground  #EDECE7   прохладная глина: фон страницы
--paper   #FBFAF7   карточки и форма
--ink     #000000   текст
--muted   #5C5B52   вторичный текст
--ghost   #7C7B71   вторая половина разорванного заголовка
--straw   #855C0C   солома текстом — единственный акцент
--straw-bar #C0911F галочки в таблице комплектов, линия над подвалом
--dusk    #0D1422   фон блока заявки
```

Цвет приходит из соломы на фотографиях. Интерфейс остаётся чернилами на листе.

сразу.

## Языки

ME · RU · EN · FR, словарь `I18N` внутри файла — 165 ключей на каждый язык.
Выбор: по браузеру, из `localStorage` или параметром `?lang=me|ru|en|fr`.
Переносы правятся под каждый язык; во французском перед `? ! : ;` и внутри
«…» ставится неразрывный пробел.

Ошибка отправки формы: `?demo=error`.

## Что проверено

- Ширины 390, 480, 768, 1024, 1280 и 1440 во всех четырёх языках (24 сочетания):
  горизонтального скролла нет, ошибок в консоли нет, все фотографии грузятся.
- Контраст всего текста на плашках — WCAG AA по вычисленным цветам, во всех
  четырёх языках.
- Контраст белого текста первого экрана — по настоящим пикселям: страница
  рендерится дважды, с текстом и без, разница даёт маску букв, и яркость фона
  считается только под штрихами. 72 элемента (4 языка × 2 ширины), худший
  результат 3,54:1 при норме 3 для крупного начертания.
- Форма: ошибки у полей, снятие ошибки по мере исправления, успех, ошибка
  сервера с сохранением введённого.
- Клавиатура: «К содержанию» первым табом, видимый фокус, меню закрывается
  по Escape и возвращает фокус, вопросы раскрываются с клавиатуры, таблица
  комплектов — фокусируемая прокручиваемая область.
- `prefers-reduced-motion`: анимация первого экрана отключается.
