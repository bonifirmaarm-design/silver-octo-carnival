# Редизайн sferihome.me

Одностраничник на фотографиях заказчика. Один файл `index.html` плюс `img/`.

Артефакт: https://claude.ai/artifact/T2nPf6jZJaxhVun9rLib6W (приватный).

## Направление

Первый экран — снимок во всю ширину, вордмарк SFERI / HOME поверх него,
плавающие плашки с цифрами. Это была просьба заказчика: экран вернуть
как был.

Остальное снято с референсов (Sonder House, Hotle, MK Vita, САК-Строй):
разорванный на чёрную и серую половины заголовок, строки данных
на волосяных линиях, пилюли как единый голос элементов, фотографии
в скруглённых карточках с отступом.

```
--ground  #EDECE7   прохладная глина: фон страницы
--paper   #FBFAF7   карточки и форма
--ink     #000000   текст
--muted   #5C5B52   вторичный текст
--ghost   #7C7B71   вторая половина разорванного заголовка
--straw   #855C0C   солома текстом — единственный акцент
--straw-bar #C0911F галочки в таблице комплектов, линия над подвалом
--dusk    #0D1422   фон блока заявки
```

Цвет приходит из соломы на фотографиях. Интерфейс остаётся чернилами на листе.

## Блоки

| Блок | Фото | Откуда приём |
|---|---|---|
| Первый экран | `house.webp` | Sonder House: вордмарк поверх снимка, плашки с цифрами |
| Солома в стене | `wall-real.webp` — настоящее | разрез стены как главный аргумент |
| Тепло | — | Sonder House: строки данных с волосяными линиями |
| Три этапа | `factory` · `assembly` · `roof` | нумерованный список |
| Участок | `piles.webp` | крупный снимок, факты рядом |
| Построено | `slope` · `sphere` · `stilts` · `flat` — настоящие | Sonder House: плитки со сдвигом, подписи под волосяной линией |
| Проекты | `aerial.webp` | САК-Строй: строки 1 / 2 / 3 этажа |
| Комплекты | — | три карточки накопительно: второй = первый плюс два пункта, третий = второй плюс два |
| Вопросы | — | `<details>`, восемь вопросов |
| Заявка | `dusk.webp` | MK Vita: белая панель формы на вечернем кадре |

Комплекты на текущем сайте — три карточки, в каждой почти один и тот же
список из пяти пунктов. Здесь список не повторяется: первая карточка
перечисляет базу, вторая говорит «всё из первого комплекта, плюс» и называет
только два своих пункта, третья — то же от второй. Различие читается за
секунду, и ничего не нужно сравнивать построчно. Третья карточка обведена
соломенным контуром и помечена «Полный».

Карточки не растянуты по высоте: во второй пунктов меньше, и пустое поле
в белой карточке выглядело бы поломкой.

## Языки

ME · RU · EN · FR, словарь `I18N` внутри файла — 165 ключей на каждый язык.
Выбор: по браузеру, из `localStorage` или параметром `?lang=me|ru|en|fr`.
Переносы правятся под каждый язык; во французском перед `? ! : ;` и внутри
«…» ставится неразрывный пробел.

Ошибка отправки формы: `?demo=error`.

## Адаптация

Брейкпоинты стоят там, где ломается содержимое, а не по списку устройств.

| Ширина | Что меняется |
|---|---|
| 1340 | ссылки в шапке уходят в бургер — четыре языковые кнопки по 44 px и «Рассчитать дом» больше не помещаются рядом с ними |
| 1100 | секции из двенадцати колонок становятся одноколоночными, карточки комплектов ужимают поля |
| 900 | «Стена» перестаёт быть двухколоночной: 400 px текста рядом с 290 px фотографии не годились ни тексту, ни фотографии |
| 780 | «Рассчитать дом» уходит из шапки — эту кнопку несёт меню |
| 700 | комплекты встают в колонку. Двух колонок не бывает никогда: третья карточка осталась бы сиротой |
| 680 | первый экран, таблица теплопроводности, слои стены и проекты перестраиваются под телефон |
| 560 | из шапки уходит слово SFERIHOME: выбор языка важнее, а имя стоит на первом экране буквами в десять раз крупнее |

Отдельное правило для телефона в альбомной ориентации (`max-height: 560px`):
первый экран 580 px в окне высотой 390 px означал, что кнопка уезжает под сгиб.
Там высота считается от окна, вордмарк и заголовок уменьшаются, плашки сужаются.

Все нажимаемые элементы — 44 px и больше, включая языковые кнопки (были 34)
и ссылки с почтой и телефоном (были 26). Планшет — тоже палец, поэтому размер
не привязан к ширине окна.

## Что проверено

- Ширины 390, 480, 768, 1024, 1280 и 1440 во всех четырёх языках (24 сочетания):
  горизонтального скролла нет, ошибок в консоли нет, все фотографии грузятся.
- Контраст всего текста на плашках — WCAG AA по вычисленным цветам, во всех
  четырёх языках.
- Контраст белого текста первого экрана — по настоящим пикселям: страница
  рендерится дважды, с текстом и без, разница даёт маску букв, и яркость фона
  считается только под штрихами. 72 элемента (4 языка × 2 ширины), худший
  результат 3,54:1 при норме 3 для крупного начертания.
- Форма: ошибки у полей, снятие ошибки по мере исправления, успех, ошибка
  сервера с сохранением введённого.
- Клавиатура: «К содержанию» первым табом, видимый фокус, меню закрывается
  по Escape и возвращает фокус, вопросы раскрываются с клавиатуры, таблица
  комплектов больше нет — карточки просто перестраиваются в колонку.
- `prefers-reduced-motion`: анимация первого экрана отключается.
- Девять устройств (телефоны 360–430, телефон в альбоме, iPad mini / iPad /
  iPad Air в обеих ориентациях) на русском и французском: горизонтального
  скролла нет, ничего не обрезано, нажимаемых элементов меньше 44 px нет,
  кнопка первого экрана видна без прокрутки.
